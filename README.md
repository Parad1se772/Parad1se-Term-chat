## ✨ Features

- 🎯 **Slash Command Support:** Simple and intuitive `/termchat` command.
- 📱 **Works Anywhere (DMs & Servers):** Built with Discord's **User Install** context system—use it in DMs, group chats, or any server without needing admin rights.
- 🖼️ **Personalized Embeds:** Displays your user display name, avatar thumbnail in the top-right corner, custom message, and a timestamp.
- 🔒 **Secure:** Clean code structured to use environment variables (`.env`) for sensitive credentials.

---

## 🖼️ Preview

When you use `/termchat message: Hello World!`, the bot responds with a clean card format:

> **Your Username**  
> Hello World!  
> *(Displays your avatar in the thumbnail corner + local timestamp)*
